Featured Projects

Autonomous Intelligent Video Surveillance & Incident Report Agent

Independent portfolio project · July 2026 – Present
  • End-to-end system combining computer vision, NLP, and agentic workflows: video ingestion, multimodal anomaly detection, knowledge retrieval, autonomous investigation, and automated reporting.
  • Two-stage multimodal detection pipeline: a vision-language model for scene perception and a separate reasoning model for structured classification, built after diagnosing a capability mismatch in a single-stage design.
  • Framework-free ReAct agent loop in pure Python (no LangChain/LlamaIndex) with custom parsing, tool-calling, and multi-step reasoning over local tools backed by SQLite.
  • Vector knowledge layer (ChromaDB, cosine similarity) that retrieves relevant Standard Operating Procedures based on incident context.
  • Deterministic, code-enforced safety guardrails (mandatory evidence-gathering gates, automated review flagging), added after finding that prompt-only instructions did not constrain a small local model well enough.
  • Runs fully on local hardware via Ollama with small open-weight models (moondream, qwen2.5).

Generative AI & LLM Engineering Intensive

Independent research & engineering project · June 2026 – Present
  • Implemented the complete Transformer architecture from scratch in PyTorch (scaled dot-product attention, multi-head attention with causal masking, sinusoidal positional encoding, LayerNorm, feed-forward blocks, residual connections), verified numerically against PyTorch's built-in implementations.
  • Built and trained a character-level GPT language model (816k parameters) from scratch on custom datasets, including Persian text.
  • Implemented LoRA from scratch, reducing trainable parameters from 100% to 1.93% while preserving model knowledge. Frozen weight change was verified to be exactly 0.00000000.
  • Built a full RAG pipeline from scratch (TF-IDF retrieval, cosine similarity ranking, context injection, grounded generation), then upgraded it to semantic embeddings with sentence-transformers and ChromaDB.
  • Applied prompt engineering techniques (zero-shot, few-shot, chain-of-thought, structured JSON output) and served LLaMA 3.1 8B locally via Ollama.
